## 新概念速览（详细版在打样里）

```css
/* Grid：二维"地砖"（flex 是一维排队） */
display: grid;
grid-template-columns: repeat(auto-fit, minmax(80px, 1fr));
/* 自动适应网格：每块至少 80px，能放几块放几块 —— 响应式不用写 @media！ */

/* 响应式：窗口 ≤600px 时执行 */
@media (max-width: 600px) { ... }
```
