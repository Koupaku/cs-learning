# 练习 04：秒表 ⏱️

> 主题：setInterval / clearInterval（定时器）
> 难度：入门 · 预计 1~2 小时
> 特别说明：**这次只给要求，不给你代码骨架提示**——结构自己搭！
> 新零件打样：`notes/04-秒表打样/`（先跑通它，再回来写）

---

## 功能要求

1. 点"开始" → 数字开始跳动（每 0.1 秒加 0.1）
2. 点"暂停" → 数字停住
3. 点"重置" → 数字归零
4. 连续点两次"开始" → 数字**不能**变快（这是隐藏要求，重点！）

## 新概念速览

```js
setInterval(函数, 毫秒)    // 每隔 N 毫秒执行一次函数，返回"计时器编号"
clearInterval(编号)        // 用编号停掉对应计时器
```

**最大的坑**：重复开启会**双倍速**。所以开始前要检查"是不是已经在计时了"（用 `running` 标志）。

## 验收标准

- [ ] 开始后数字 0.1 秒一跳
- [ ] 暂停后完全停住
- [ ] 重置后回到 0.0 秒
- [ ] **疯狂连点开始，速度不变**（这个过了，说明你避开了最大的坑）

## 加分项

1. **格式升级**：显示成 `00:05.3`（分:秒.毫秒）
