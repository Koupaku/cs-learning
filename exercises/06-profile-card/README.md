# 练习 06：个人名片 👨‍💻

> 主题：HTML 语义化 + CSS 盒模型 + Flexbox 布局
> 难度：入门 · 预计 2~3 小时
> 意义：阶段 2「装修课」第一站——把"能用"变成"好看"。
> 新零件打样：`notes/06-CSS基础打样/`（先打开它！）

---

## 你要做的东西

一张个人名片卡片：圆形头像 + 名字 + 一句话介绍 + 技能标签 + 按钮。

## 你的任务（style.css 里 5 个 TODO）

| TODO | 做什么 | 用到的知识 |
|------|--------|-----------|
| 1 | 卡片在屏幕正中间 | flex + 居中大法 + 100vh |
| 2 | 卡片本体：圆角、阴影、内边距 | 盒模型三件套 |
| 3 | 头像变圆形 | border-radius: 50% + flex 居中 |
| 4 | 标签排成一行 | flex + gap |
| 5 | 按钮悬停变色的过渡动画 | :hover + transition |

index.html 结构已经给好了，你只写 CSS——**这是你第一次"纯装修"**。

## 验收标准

- [ ] 卡片在屏幕正中间（水平 + 垂直）
- [ ] 头像是个圆，emoji 在圆正中
- [ ] 三个标签一行排开，间距均匀
- [ ] 鼠标悬停按钮 → 颜色平滑变深
- [ ] 卡片有圆角和阴影，不是"平铺"在页面上

## 加分项

1. **响应式**：屏幕变窄时卡片自适应（提示：`max-width: 360px` 给卡片限宽）
2. **卡片悬停**：鼠标放在卡片上时卡片微微上浮（提示：`.card:hover { transform: translateY(-4px); }` + transition）
3. **深色模式**：用 `@media (prefers-color-scheme: dark)` 给深色系统换一套配色
