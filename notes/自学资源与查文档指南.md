# 自学资源与查文档指南 📚

> 用途：练习里遇到不懂的属性/方法/概念时，去哪里学、怎么学
> 配合作业使用：白天做练习 → 遇到不懂查这里 → 晚上看视频补课

---

## 0. 先端正一个心态（重要！）

**程序员不背 API，查文档是核心技能。**

`textContent`、`appendChild`、`setInterval`……这些成百上千，**没有人全背下来**。真正的区别是：

- 菜鸟：遇到不懂的 → 卡住 → 放弃 / 瞎猜
- 老手：遇到不懂的 → **知道去哪查、怎么查** → 3 分钟搞懂 → 继续写

所以你现在"看不懂属性和方法"**不是问题**，问题只在于你还没有"查"的习惯和工具。看完这份指南，你就有了。

---

## 1. 查文档五步法（以 MDN 为例）

**MDN（Mozilla 开发者网络）是前端第一权威文档**，有完整中文版。

**网址**：`https://developer.mozilla.org/zh-CN/`

**五步法**（拿 `textContent` 举例）：

1. **在地址栏搜**：`MDN textContent`（或直接进 MDN 站内搜）
2. **打开对应页面**，先看开头一两段"它是什么"
3. **跳到"语法"小节**：看它怎么用、返回值是什么
4. **看"示例"（关键！）**：直接抄一个跑一跑
5. **关掉页面，用你自己的话写一遍**：能写出来 = 学会了

> 中文搜不到想要的，就搜英文（比如 `MDN addEventListener`）——英文资料多 10 倍。

## 3. 遇到新属性的标准流程（贴在脑子里）

```
做练习遇到不认识的 xxx（属性/方法）
      ↓
① 先猜：看名字猜意思（textContent = 文字内容？addEventListener = 添加事件监听？）
② 查：MDN 搜 xxx，看"语法"和"示例"
③ 抄：复制示例到你的文件里跑一遍
④ 用：把它用到你的练习里
⑤ 记：写进 notes/前端词汇手册.md（你的私人词典）
```

**猜名字 → 查文档 → 抄跑 → 使用 → 入库**，五步走完，这个 API 就是你的了。
