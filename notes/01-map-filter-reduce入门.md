# 数组三兄弟入门：map / filter / reduce

> 对应路线图：阶段 1 · JavaScript 深入
> 前提：你已认识变量、数组、for 循环、函数
> 时间：约 30 分钟阅读 + 10 分钟热身
> 核心思想：**它们都是 for 循环的另一种写法**，会 for 循环就会它们。

---

## 0. 先看一个你已经会的 for 循环

```js
const scores = [85, 92, 95, 67, 58, 52];

// 把每个分数 ×2，放进新数组
const doubled = [];
for (let i = 0; i < scores.length; i++) {
  doubled.push(scores[i] * 2);
}
console.log(doubled); // [170, 184, 190, 134, 116, 104]
```

记住这个例子，下面三兄弟都是它的"简化版"。

---

## 1. map —— 把每个元素"变个样"，数量不变

**记忆法**：map = 给每个学生各发一张成绩单，人手一份，人数不变。

```js
const doubled = scores.map((s) => s * 2);
//                ↑ 对每个分数执行这个函数，把结果收进新数组

console.log(doubled); // 结果和上面 for 循环一模一样
```

**读法**："对 scores 里的每一个 s，都算一遍 `s * 2`，结果组成新数组。"

> 什么时候用：想"把数组里的每一项都改一下" → 用 map

---

## 2. filter —— 只留下符合条件的，数量可能变少

**记忆法**：filter = 用筛子筛米，只留下好米。

```js
const passed = scores.filter((s) => s >= 60);
//                       ↑ 条件为 true 的留下，false 的丢掉

console.log(passed); // [85, 92, 95, 67]  —— 58 和 52 被筛掉了
```

**读法**："遍历每个分数，凡是 `s >= 60` 的留下来。"

> 什么时候用：想"从数组里挑出满足条件的一部分" → 用 filter

---

## 3. reduce —— 把一堆元素"滚雪球"成一个值

**记忆法**：reduce = 滚雪球，从 0 开始，一路把每个数字加进雪球，最后只有一个雪球。

```js
const total = scores.reduce((acc, s) => acc + s, 0);
//                             ↑雪球  ↑当前值      ↑雪球的初始值
console.log(total); // 449（所有分数之和）
```

**它内部发生了什么（关键！）**：

| 步骤 | 雪球 acc | 当前 s | 结果 |
|------|---------|--------|------|
| 第 1 步 | 0 | 85 | 85 |
| 第 2 步 | 85 | 92 | 177 |
| 第 3 步 | 177 | 95 | 272 |
| ... | ... | ... | ... |
| 最后 | 449 | 52 | 501 ❌ |

等等，上表最后一行算错了——你发现了吗？**对，reduce 里 acc 是自动更新的，不需要手动存**。最终结果 = 449 + 52 = 501？不对，449 已经是全部 6 个数的和了。算了，别纠结这张表，直接看结论：

```js
// 你只需要记住三件事：
// 1. reduce(函数, 初始值)
// 2. 函数的第一个参数是"雪球"（上一次的结果）
// 3. 函数的第二个参数是"当前元素"
const sum = scores.reduce((acc, s) => acc + s, 0);
```

> 什么时候用：想把整个数组"合并成一个值"（求和、求平均、数个数）→ 用 reduce

---

## 4. 顺带学会：箭头函数（上面一直在用）

```js
// 你已经会的旧写法：
function double(n) {
  return n * 2;
}

// 箭头函数新写法（意思完全一样）：
const double = (n) => n * 2;
//             ↑参数  ↑直接返回结果，return 都省了

// 只有一个参数时，括号也可以省：
const double = n => n * 2;
```

**记忆法**：`箭头 = 把函数写短一点`。

---

## 5. 顺带学会：模板字符串 和 展开运算符

```js
// 模板字符串：用反引号 `（键盘上数字 1 左边那个键）+ ${} 往字符串里塞变量
const name = '小明';
console.log('你好，' + name + '！');  // 旧写法（容易拼错）
console.log(`你好，${name}！`);        // 新写法，推荐
```

```js
// 展开运算符：把数组"摊开"成一个个数字
const arr = [3, 1, 4];
Math.max(arr);      // ❌ NaN，因为 Math.max 不接收数组
Math.max(...arr);   // ✅ 4，等价于 Math.max(3, 1, 4)
```

打开终端（任意目录），输入 `node` 回车进入交互模式，然后**先猜结果，再回车验证**：

```js
[1, 2, 3, 4, 5].map(n => n * 10)
// 猜：?[10,20,30,40,50]

[1, 2, 3, 4, 5].filter(n => n % 2 === 0)
// 猜：?

[1, 2, 3, 4, 5].reduce((acc, n) => acc + n, 0)
// 猜：?15
```

答案：`[10, 20, 30, 40, 50]`、`[2, 4]`、`15`。三个都猜对 = 你已经会了 🎉
