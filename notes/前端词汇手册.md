## 0. 最重要的两个概念：属性 vs 方法

| | 属性（property） | 方法（method） |
|---|---|---|
| 是什么 | 名词——物体"有什么" | 动词——物体"能做什么" |
| 例子 | 人的**年龄**、**名字** | 人的**跑()**、**吃()** |
| JS 里 | `对象.属性` | `对象.方法()` ← **方法带括号！** |
| 例子 | `element.textContent`（元素的内容） | `element.appendChild(x)`（把 x 挂上去） |

**判断口诀**：后面有括号 `()` 的是方法（要执行动作），没括号的是属性（直接读值）。

## 1. DOM 元素（练习 2~7 天天用）

| 名字 | 属性/方法 | 人话 | 例子 |
|------|----------|------|------|
| `textContent` | 属性 | 元素里的文字（读写都行） | `msg.textContent = '你好'` |
| `value` | 属性 | 输入框里的内容 | `todoInput.value` |
| `style` | 属性 | 元素的样式（CSS） | `btn.style.display = 'none'` |
| `className` | 属性 | 元素的 class 标签（JS 读写用 className） | `status.className = 'error'` |
| `dataset` | 属性 | 元素上所有 `data-xxx` 属性 | `btn.dataset.city` |
| `innerHTML` | 属性 | 元素内部的所有 HTML（可清空） | `list.innerHTML = ''` |
| `getElementById()` | 方法 | 按 id 抓元素 | `document.getElementById('app')` |
| `querySelectorAll()` | 方法 | 按 CSS 选择器抓一堆元素 | `document.querySelectorAll('.btn')` |
| `createElement()` | 方法 | 凭空造一个元素 | `document.createElement('li')` |
| `appendChild()` | 方法 | 把元素挂到另一个元素里 | `list.appendChild(li)` |
| `addEventListener()` | 方法 | 给元素装"触发器" | `btn.addEventListener('click', fn)` |
| `focus()` | 方法 | 让光标进到输入框 | `input.focus()` |

## 2. 数组（练习 1、3）

| 名字 | 人话 | 例子 |
|------|------|------|
| `map()` | 每个元素变个样，长度不变 | `scores.map(s => s * 2)` |
| `filter()` | 筛出符合条件的 | `scores.filter(s => s >= 60)` |
| `reduce()` | 滚雪球成一个值 | `scores.reduce((a, b) => a + b, 0)` |
| `forEach()` | 每个元素做件事（不管结果） | `todos.forEach(t => renderOne(t))` |
| `push()` | 往末尾加一个 | `todos.push(newTodo)` |
| `length` | 长度（属性，无括号） | `students.length` |
| `join()` | 数组变字符串，用分隔符连 | `[1,2,3].join(', ')` → `"1, 2, 3"` |

## 3. 对象（你朋友教程 + 练习 3/5/7）

| 名字 | 人话 | 例子 |
|------|------|------|
| `{ key: value }` | 字典：钥匙 → 内容 | `{ 北京: { lat: 39.9 } }` |
| `对象.属性` | 点号取内容 | `cities.北京` |
| `对象[变量]` | 中括号里可以放变量（算完再查） | `cities[city]` |
| 解构 `{ a, b } = obj` | 一把抓出几个属性 | `const { lat, lon } = cities[city]` |
| `Date.now()` | 当前毫秒时间戳（当唯一 id） | `{ id: Date.now() }` |
| 属性简写 `{ text }` | 属性名 = 变量名时写一遍即可 | `{ id: 1, text }` = `{ id: 1, text: text }` |
| ⭐ 属性**顺序不重要** | 对象按**名字**取，不按位置（数组才按位置） | `{a:1,b:2}` 和 `{b:2,a:1}` 一样 |
| ⭐ 对象 = "君子协定" | 缺字段**不报错**，只返回 undefined → 静默 bug 之源 | `{id:1}` 里取 `.done` → `undefined` |

## 4. 字符串 & 数字工具

| 名字 | 人话 | 例子 |
|------|------|------|
| `.trim()` | 去掉首尾空格 | `'  hi  '.trim()` → `'hi'` |
| 模板字符串 | 反引号 + `${}` 塞变量 | `` `你好，${name}` `` |
| `.toFixed(n)` | 保留 n 位小数（返回字符串） | `(3.14159).toFixed(2)` → `'3.14'` |
| `Number(x)` | 把东西转成数字 | `Number('42')` → `42` |
| `JSON.stringify(x)` | 把数据变成字符串 | 调试时看清引号用 |
| `Math.random()` | 0~1 随机小数 | 游戏用 |
| `Math.floor(x)` | 向下取整 | `Math.floor(3.9)` → `3` |
| `Math.max/min(...)` | 找最大/最小（记得展开） | `Math.max(...scores)` |
| `Math.round(x)` | 四舍五入到整数 | `Math.round(3.6)` → `4` |

## 5. 定时器 & 异步（练习 4、5、7）

| 名字 | 人话 | 例子 |
|------|------|------|
| `setInterval(fn, 毫秒)` | 每隔一段时间执行一次，返回编号 | `setInterval(tick, 100)` |
| `clearInterval(编号)` | 用编号停掉定时器 | `clearInterval(timer)` |
| `setTimeout(fn, 毫秒)` | 延迟执行一次 | 打样里见过 |
| `fetch(网址)` | 去网上要数据（异步） | `await fetch(url)` |
| `async function` | 里面才能用 await | 异步函数的许可证 |
| `await xxx` | 等到号再继续 | `await response.json()` |
| `try { } catch(e) { }` | 试试看，出错就接住 | 网络报错兜底 |
| `??` | 左边是空就用右边兜底 | `map[code] ?? '❓'` |
