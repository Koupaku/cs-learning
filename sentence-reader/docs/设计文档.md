# 「逐句阅读器」产品与技术设计文档

> 工作名：**sentence-reader**（暂定中文名：「逐句阅读」/ 副标题候选：沉浸式文本阅读）
> 状态：v0.1 设计稿（待讨论定稿）
> 日期：2026-02（本会话）

---

## 0. 一句话定义

用户导入 TXT 文档（首版），阅读器自动把正文切成**句子流**，以**视觉小说/文字游戏的呈现方式**逐句阅读：
每按一次按键（鼠标 / 键盘 / 触屏 / 手柄）推进一句，文本在一个有界的"对话面板"里累积；面板放不下时自动**翻页**，
翻页同时**更换背景图**；阅读进度自动保存，随时续读。

**核心目标不是"读得快"，而是"读得进去"**——用主动节奏 + 渐进披露 + 多通道刺激对抗读名著时的注意力涣散。

---

## 1. 核心假设与验证（先于功能）

| 假设 | 验证方法 |
|---|---|
| H1：逐句点击推进能让我读完一本完整名著 | 首版跑通后，自己选一本完整章节做实测：读完 ≥ 3 章 |
| H2：效果不是纯新鲜感 | 同一章节 A/B：普通滚动阅读 vs 逐句模式；对比①完成率 ②回看次数 ③事后回忆要点数。若两周内效果衰减明显，产品需保留普通模式切换（M3 内建） |
| H3：背景图增强而非干扰专注 | 设置里提供"背景强度 0–100%"滑块 + 关图纯色模式；记录用户实际倾向 |

**"快"不是指标，"进入心流并读完"才是。**

---

## 2. 范围（版本线）

- **M0 可玩原型（单页）**：导入 TXT → 分章 → 断句 → 逐句点击推进 + 回看 + 换背景 + 进度保存。一天内可跑通。
- **M1 完整阅读体验**：书架多书、设置面板、手柄/触屏完善、背景三层来源齐全、PWA 离线。
- **M2 增强**：TTS 朗读同步高亮、注释/生僻字注音、普通模式切换、统计（时长/字数/连续天数）。
- **M3+（暂缓）**：EPUB 支持、背景按章节关键词/情绪匹配、导出 WebGAL 剧本。

首版只做 **M0 + M1 的核心子集**（见 §6 里程碑）。EPUB/PDF 一律不做（PDF 明确不做）。

---

## 3. 名词与数据模型

```
Book       一本书        { id, title, sourceFileName, chapters: Chapter[], createdAt, lastReadAt }
Chapter     章节         { index, title?, sentences: Sentence[] }   // 惰性断句：可只断当前章
Sentence    句子         { text, isDialogue?, isParagraphStart? }   // 见 §5 断句
Session     阅读会话位置  { bookId, chapterIndex, sentenceIndex, pagePos? }
Settings    用户设置     见 §8
```

约束：**一本书的阅读位置永远落在 (chapterIndex, sentenceIndex)，而不是像素**——翻页由渲染层实时计算，改字体/窗口大小不丢位置（对齐句，而不是对齐页）。

## 4. 用户流程

```
[书架] --导入 TXT--> [解析中: 编码检测→分章→(按需)断句] --> 进入阅读
[阅读] 点击/按键推进一句 → 面板溢出 → 自动翻页 + 换背景
       B/Back = 回上一句 | 长按或肩键 = 回上一章开头
       Esc/Start = 呼出菜单（章节跳转 / 设置 / 返回书架 / 进度）
[退出] 位置自动存入 IndexedDB，下次打开直接续读
```

导入入口（M0 两种并存）：
1. `<input type="file">` 选择 `.txt`（跨浏览器最稳）。
2. 拖拽文件到窗口。
3. （M1+）目录级导入：`File System Access API`（Chromium），读取用户**本地图片文件夹**路径授权。

## 5. 文本管线（核心难点，单独一节）

### 5.1 编码检测
TXT 常见 UTF-8 / GBK / UTF-16LE / GB18030。
方案：读 ArrayBuffer → 依次尝试 UTF-8（严格校验，失败即非）、UTF-16 BOM、GB18030（可用 `jschardet` 或 TextDecoder 逐编码试解 + 替换字符率打分）。M0 至少保证 UTF-8 + BOM + GBK。

### 5.2 分章
正则匹配章标题行。规则（可配置，默认按优先级匹配）：

```text
第[一二三四五六七八九十百千0-9０-９]+[章回节卷部集]
（行首，且独立成行 / 行尾无正文）
```

辅规则：若全文无任何章标题命中 → 按固定字数（如 5000 字）或空行分块，仅作"长文分块"用。
章标题本身作为 Chapter.title 存储并在翻页时展示（"第 X 章"动效节点）。

### 5.3 断句（Splitting Sentences）——重点设计

**目标**：把段落切成适合逐句阅读的"呼吸单位"，语义尽量完整，长度尽量 ≤ 面板 3–4 行。

**输入预处理（按段落）**：
1. 折叠空白、去行首缩进痕迹；空行保留为"段落边界标记"。
2. 段落起始识别：引号开头（`"`/`“`/`『`）或 段首缩进 → 标记 `isParagraphStart`，播放时给段落首句加停顿/缩进提示。

**切分规则（按优先级）**：

| 优先级 | 规则 | 说明 | 示例 |
|---|---|---|---|
| 1 | 句末标点 `。！？…`（含全半角）切句 | 主切分点 | `天黑了。他还没回来。` |
| 2 | 后引号归属：`…。”` / `…！”` 整块收进前一句 | 避免把 `"你来了。"` 拆成 `"你来了。` + `"` | `“回来吧。”她说。` → 先按规则 1 切成 `“回来吧。”` 和 `她说。`（正确：前句含后引号） |
| 3 | 冒号+引号开启对话时，冒号**不**断（避免 `他说：` 独立成句） | `他说：` 与引语粘连 | `他说：“我不知道。”` 保持一整句或按引语内容再分 |
| 4 | 超长句（字符数 > 阈值，默认 60–80 字，可配）在**次级断点**处分：`，、；：` 与空格/破折号 | 优先在语义停顿处断，禁止在引号中间断 | 长复句在逗号处切，注意别断在 `“` 内部 |
| 5 | 分号 `；` 默认**切**（两个完整小句），可配为"不切"（若要保留排比气势） | 提供设置项"分号断句：开/关" | `风停了；雨住了。` |
| 6 | 破折号/省略号居中排的诗词、对话行不参与自动切 | 只对"整段成诗"做整体块处理 | 见下方"诗词/特殊行" |

**特殊行处理（名著常有）**：
- 仅含引号/无标点结尾的连续对话行（戏剧式），按**换行**为句界。
- 诗词（七律等）：整首/整联作为一个"块"，逐句可切但**禁止按字数腰斩**；检测启发式：行短 + 无标点 + 行数多。
- 章节标题、版权页、目录行：分章阶段剔除。

**实现建议**：先正则粗切 → 再状态机细调（引号配对栈：处理跨段对话、未闭合引号兜底到段尾）。每个规则配 3–5 个单元测试用例（见 §12 测试用例表）。

**对话标记**：句首为引号（`“`/`"`/`「`/`『`）→ `isDialogue = true`，渲染时可选高亮（淡色引号/缩进），增强文字游戏感。

### 5.4 惰性断句
解析只做"分章 + 段落结构"，断句在进入章节时再执行（书很大时避免一次性全断）。句子流可缓存到 IndexedDB。

## 6. 阅读播放器（渲染层）

### 6.1 布局模型（M0 采用"有界面板累积式"，即用户原案）

```
┌──────────────────────────────────────────┐
│  背景层：图片/程序化画面（全屏）            │
│  ├── 可读性遮罩：压暗+模糊渐变             │
│  └── 对话面板（屏幕下部/居中，约 30–45% 高）│
│        ┌────────────────────────────┐    │
│        │ 当前句/已累积句（可回看）     │    │
│        │ 段落首句缩进/停顿提示        │    │
│        └────────────────────────────┘    │
│  顶部细条：进度（章 3/12 · 句进度）        │
│  底部提示：继续 ▸（淡出）                  │
└──────────────────────────────────────────┘
```

- 面板高度固定（按视口比例 + 字号设置计算）。
- 每推进一句：`Sentence` append 进面板内容区；**内容溢出检测**（内容 scrollHeight > 可视高度）→ 触发翻页。
- **翻页语义**：把"当前这句"作为新页第一句，前面内容入历史；背景换一张。
- **页面历史**：`pageStack` 支持回退到上一页整体（长按 Back 逐页回退），而不是只能回一句。
- 面板内最多保留 N 句（如最近 6–10 句）时允许滚动回看本页，超出进历史页。

### 6.2 输入层：统一"动作"抽象

所有输入源映射到少数动作，播放器只监听动作，不关心来源：

| 动作 | 鼠标 | 键盘 | 触屏 | 手柄（Gamepad） |
|---|---|---|---|---|
| 推进一句 | 左键 / 滚轮下 | `Space` / `→` / `↓` / `Enter` | 点右 2/3 区域 | A / 十字键下 |
| 回上一句 | 右键 / 滚轮上 | `←` / `↑` / `Backspace` | 点左 1/3 区域（可关） | B / 十字键上 |
| 回上一页(整体) | — | `PgUp` / `[` | 长按左区 | LB 长按 / 十字键左 |
| 下一章 | — | `PgDn` / `]` | — | RB |
| 菜单（章节跳转/设置/书架） | 点顶栏图标 | `Esc` | 点顶栏图标 | Start |
| 隐藏 UI（禅模式） | — | `H` | 双指双击 | — |

- 手柄用 `navigator.getGamepads()` + `requestAnimationFrame` 轮询，**边沿触发**（`pressed && !prevPressed`），防连发；`gamepadconnected/disconnected` 时在界面顶部提示，避免"按了没反应"的困惑。
- 全部按键可重映射（M1 设置）。
- 无障碍：字号、对比度可调（见 §8）。

### 6.3 回看与导航
- 上一句 / 上一页整体 / 章节跳转（菜单内章节列表）。
- 长文回看后提供"回到最新位置"按钮（按进度高亮显示），避免迷失。

### 6.4 禅模式与 UI 消退
- 3 秒无操作隐藏鼠标/进度条；任意输入唤回。进度细条常驻 1px 底线。

## 7. 背景系统（三层来源，M0 先做 ②③，① 紧随其后）

### 7.1 来源
1. **用户本地文件夹**（用户已选）：授权目录后，App 扫描该目录（及子目录）图片（jpg/png/webp）；**不拷贝**，仅存路径引用 + 缩略图缓存（IndexedDB）。
   - M0 兜底：用户通过 `<input type=file multiple accept=image/*>` 一次性导入若干张图（避开权限 API 兼容问题）。
2. **内置风格包**：随应用打包 3–4 组底图（古典/山水、赛博、自然、黑白纹理）。可程序化生成后导出，或用无版权图库（注明来源）。每组 10–20 张，循环不重样。
3. **程序化生成**（Canvas）：参数化生成"氛围画面"：
   - 模式候选：① 深色渐变 + 缓慢浮动的粒子/光斑 ② 噪点纹理 + 缓慢色彩漂移 ③ 极简几何光影（类似专辑封面）④ 山峦/波浪分层剪影动画。
   - 每页生成一帧静态画面或持续极缓动画（< 10 fps 变化，避免干扰）。
   - 优点：无限不重样、零版权、尺寸自适应。作为**默认模式**与"无图可读性对照"。

### 7.2 切换逻辑
- 触发点：**翻页时**（与用户描述一致）+ 章节完成时（大背景切换作为"节奏标记"）。
- 模式设置：`随机不重样`（洗牌队列，默认）/ `顺序循环` / `按心情手动换`（菜单里"换背景"）。
- **相关性匹配留到 M3**（关键词标签 → 图片 tag），M0–M1 明确不做自动理解。

### 7.3 可读性工程（不可省）
- 背景之上固定叠加遮罩层：底部向文字面板方向加深（CSS 渐变）+ 背景层低饱和处理（`filter: saturate(0.8) brightness(0.5)` 或 canvas 预渲染）。
- 文字面板本身：半透明深色（`rgba(10,12,16,.72)`）+ 细描边/阴影，保证任意背景可读。
- 背景强度滑块 0–100%：0 = 纯色阅读模式（对照实验用）。

### 7.4 动效
- 翻页换背景：交叉淡入淡出 600–900ms（CSS opacity transition，双图栈实现）。
- **禁止硬切**；程序化模式淡入本身即切换。
- 图片预加载：维护 2 张预取缓冲，翻页零等待；性能预算：单图 ≤ 1.5MB 自动降采样。

## 9. 技术选型与架构

### 9.1 选型（理由一句话）
- **Vite + TypeScript + React**（工作目录已有 React 学习项目，生态与心智负担最小；组件树浅，SSR 无需求）。
- **Tailwind CSS**：样式迭代快，深色主题容易做。
- **IndexedDB**：封装一个轻量 `store.ts`（book / sentences / settings / imageThumbs），不引重型 ORM；M0 可先用 localStorage 存进度，M1 迁 IndexedDB。
- **PWA**（M1）：manifest + service worker 缓存 shell 与内置图包，`beforeinstallprompt` 允许"安装到桌面"。
- 无后端、纯本地。TXT 解析不进主线程：断句在 Web Worker 里做，长书不卡 UI。

### 9.2 模块图

```
pages/       书架页 | 阅读页 | 设置抽屉
text/        TextSource(接口) → TxtSource(编码检测→分章)
             Splitter(段落→句子流, 状态机)        [Worker]
             splitRules + split.spec 测试用例
player/      PlayerStore(状态机: idle/reading/menu)
             PageLayout(溢出检测→翻页) | HistoryStack
             InputHub(鼠标/键盘/触屏/Gamepad→Action)
bg/          BackgroundController(来源切换/预加载/双图淡入)
             procedural/ (Canvas 生成器)
persist/     db.ts(IndexedDB) | progress.ts | settings.ts
ui/          面板、进度条、菜单、禅模式
```

**关键原则：text 管线与 player 解耦**——Splitter 只输出句子流；Player 只消费句子流。未来换 EPUB 源、或导出 WebGAL 剧本，都只动 text 层。

### 9.3 关键实现要点
- **溢出检测翻页**：句子 append 后 `requestAnimationFrame` 检查 `panel.scrollHeight > panel.clientHeight`，若溢出则把当前句移入新页。注意**不要**在 setState 同帧判断（布局未提交），用双帧或 `ResizeObserver`。
- **句子级定位**：面板只渲染"当前页句子区间 [pageStart, pageEnd)"；页面区间由"逐句模拟布局"或"溢出回退"算出，避免 DOM 里堆全章节点（长文性能）。
- **Gamepad 轮询**：单例 `rAF` 循环只在"有手柄连接"时运行；动作队列去抖 50ms。
- **背景双图栈**：`bgA`(当前) + `bgB`(目标) 交替 opacity，预取 `next()`。
- **Worker 断句**：主线程收到 `{paragraphs}` → worker 返回 `{sentences, meta}`；大书按章调用。

## 10. PWA 与隐私

- 数据 100% 本地；不上传文档、图片、进度（除非未来用户显式开启同步）。
- 导入大 TXT（>20MB）提示分章处理，避免一次性全载入内存。
- 离线可用：shell + 内置图包 + 已导入书缓存。

## 12. 断句单元测试用例（初稿，M0 实现时补齐）

```text
输入 -> 期望切分
1. 天黑了。他还没回来。            -> [天黑了。] [他还没回来。]
2. “回来吧。”她说。               -> [“回来吧。”] [她说。]
3. “你……”“别说了！”他打断。      -> [“你……”] [“别说了！”] [他打断。]
4. 他说：“我不知道。”             -> [他说：“我不知道。”] 或 [他说：] [“我不知道。”]？(拍板: 默认整句保留)
5. 长句超过阈值，在逗号处分…（60+字示例） -> 逗号处切，不得断在引号内
6. 风停了；雨住了。               -> 默认: [风停了；] [雨住了。]（规则5开）/ 不开则整句
7. 诗歌段落（无标点短行×N）       -> 按行切
8. 跨段未闭合引号（“…段尾无闭合，下段闭合） -> 引号状态跨段继承
9. 数字/年份含点号：3.14、2026.1.1 -> 不切
10. 省略号……、连续感叹！！        -> 归一后整体切
```
