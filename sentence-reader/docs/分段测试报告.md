# 《百年孤独》全本断句实测报告

> 测试对象：`【名著】《百年孤独》（校对全本）作者：加西亚·马尔克斯_著_黄锦炎译.txt`
> 日期：2026-02　|　配套代码：`tools/probe.mjs`（结构探针）、`tools/split.mjs`（文本管线）、`tools/audit.mjs`（抽样审计）

---

## 1. 方法

按设计文档 §5 的管线流程实测：**解码 → 清噪/分章 → 段落组装（含续行合并）→ 断句（主切分+分号切+超长软切）→ 统计 + 分层随机抽样人工审计**。

断句配置（对应 §8 Settings 默认值）：

```js
{ longThreshold: 72, minFrag: 8, semicolonSplit: true, attributionSplit: true }
```

> `attributionSplit`（§13#1 拍板）：冒号后紧跟引号 → 在冒号处切，`他说：` 成为说话人标签式单元。

审计方式：全本 796 段中按章分层随机抽 41 段（固定随机种子，可复现），把单元用 `│` 渲染后逐条判读切点是否"读起来顺"。判据：①同句腰斩到语义断裂 ②两句粘连 ③悬空引号/标点碎片 ④明显该切未切 → 记一次错误。

## 2. 源文件结构实测（探针结论）

| 项目 | 实测值 | 对管线的意义 |

## 4. 审计结果与发现的边界情形

### 4.1 错率实测
41 段 / ~600 单元人工判读：**发现 1 个硬错误**（第八章页码残留垃圾单元 `·120．`），2 处观感级边界情形。按设计文档 §11 验收标准（断句错率 < 5%）**通过**。两类错误均已在管线中修复/记录。

### 4.2 修复的问题（bug 清单）
1. **splitLong 只从尾部切**（头部巨块永不分解）→ 改为从头部贪心切，每块 ≤ 阈值；max 从 1171 → 88 字，>120 归零。
2. **独立行页码标记 `-n-` 漏网**（`·120．` 型）→ 行级正则扩展。
3. **段内粘连页码 `·218．`**（OCR 把页码贴进句子）→ 段落级清洗。

### 4.3 验证通过的规则（实测支持 §5.3 设计）
- 主切分（。！？…）+ 后引号吸收：全本干净，无粘连两句话的单元（审计 0 例）。
- **说话人标签切分**（§13#1 拍板，`attributionSplit`）：`他说：` 与引语分离成独立单元，观感类似游戏"说话人 + 台词"（199 个冒号标签单元，短标签 ≤8 字 49 个；如 `她丈夫回答说：` / `他说：`）。
- 分号切 + "分号后跟引号不切"（OCR 的 `回答说；"` 变体）：成立。
- 引号外逗号软切超长句：成立，切点语义完整（例：第十九章 250 字"蟑螂长句"切成 5 个 35–60 字单元）。
- 段落续行合并（行尾引号未闭合/以逗号结尾 → 与下行合并）：修复了源文件里"引语跨行"的断段（如 `……事情，` + 下行 `他对乌苏拉说……`）。

### 4.4 记录在案的观感边界（非错误，策略取舍）
1. **引号内按句号切**（44 例）：长段演讲含多个句号时，每个句号自成单元，中间单元不带引号、闭合引号落在最后一段（例：`“只是有两个条件，”他接着说，“首先……粉墙； │ 第二，上兵应立即离开马贡多。 │ 社会治安由我们担保。”`）。副标题式阅读可接受；若反感可改为"引号内不切，整段演讲合并"（会产生 100+ 字单元）。
2. **超长句逗号收尾单元**（663 例中的多数）：>72 字且句内无句号的长句，在逗号处切成"上一单元以逗号收尾"的续行形式，副标题常见手法，观感可接受。
3. **说话人归属独立成单元**（例：`“不用害怕，那是兔子。” │ 佩特拉·科特对他说。`）：按句号切分的自然结果，点击流为"台词→旁白"，可接受；后续可在渲染层把 ≤N 字的"某人说"短单元与上一句视觉合并。

## 5. 结论与后续

- 断句器对本文件质量达标（>95% 切点语义正确），规则配置与设计文档一致，可直接进入 M0 阅读器原型。
- 产物：`tools/out/book.sentences.json`（章节→单元数组，含段首/对话标记字段，0.37 MB，可直接被阅读器消费）；`split-report.txt`（统计）、`audit-sample.txt`（审计样本）。
- 待决策项（不影响管线跑通）：
  1. 引号内长演讲的切分观感（现状 vs 合并整段）；
  2. "序章"（译者长序）默认是否纳入阅读流（建议书架里单独标记，可跳过）；
  3. 换第二本书（不同译本/排版）验证管线鲁棒性后再冻结规则。
